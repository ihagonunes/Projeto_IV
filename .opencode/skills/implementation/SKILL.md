# Implementation

Antes de implementar:

1. identifique a fronteira da mudança;
2. localize implementações semelhantes;
3. reutilize padrões existentes;
4. evite abstrações prematuras.

Depois:

1. escreva testes;
2. implemente;
3. execute checks;
4. revise o diff.

Não altere arquivos fora da fronteira da tarefa sem justificativa.
