# Contexto progressivo

Leia `AGENTS.md` primeiro e consulte `ai/context-map.md` para decidir o próximo arquivo. Não carregue documentos por curiosidade. Para alterações, delimite a fronteira pelos caminhos do plano, pelo diff e pelas dependências diretas. Se o contexto estiver incompleto, declare a lacuna e peça o arquivo específico em vez de abrir o repositório inteiro.
