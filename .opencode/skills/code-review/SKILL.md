# Code Review

Analise primeiro:

- comportamento incorreto;
- edge cases;
- regressões;
- contratos;
- segurança;
- concorrência;
- tratamento de erros;
- testes.

Não transforme revisão em refactor geral.
Não reporte apenas estilo.
Cada finding deve ter evidência e impacto.
