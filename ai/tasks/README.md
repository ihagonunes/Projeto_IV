# Task packets

Para tarefa recorrente, crie `TASK-<id>-<nome>.md`.

```md
# TASK-000 — Título
## Objetivo
## Fora de escopo
## Critérios de aceitação
## Módulo proprietário
## Contexto
- ai/...
## Arquivos prováveis
- src/...
## Checks
- ./scripts/check --changed
- ./scripts/check
```

Não copie arquitetura global para task packets; referencie arquivos canônicos.
